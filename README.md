# 💸 My Expense Tracker

A simple expense tracker web app that helps you track your money **and your mood** while spending.

🔗 **Live link:** sparkling-tulumba-73a1a6.netlify.app

## Features

- Add expenses with amount, category, date and a note
- Delete expenses
- Filter expenses by category
- Set a monthly budget with a progress bar (green / orange / red)
- **Safe to spend per day:** shows how much you can spend each day for the rest of the month
- **Mood tracking:** tag each expense as 😊 worth it, 😐 needed it or 😬 regret it
- **Regret money:** shows how much money you spent on things you regret
- **Work hours:** shows how many hours of work each expense costs you
- Pie chart of spending by category
- Dark mode
- Data is saved in the browser, so it stays after refreshing

## Tech Used

- HTML
- CSS
- JavaScript
- Chart.js (for the pie chart)
- localStorage (to save data)

## How to Use

1. Set your monthly budget
2. (Optional) Enter your hourly income
3. Add an expense with amount, category, date, note and mood
4. See your spending in the table, summary cards and pie chart
5. Use the filter to see one category, or Delete to remove an expense

## How to Run

Just open `index.html` in any browser. No installation needed.

## Project Files

- `index.html` – structure of the page
- `style.css` – design and dark mode colours
- `script.js` – all the logic (adding, deleting, budget, chart, saving)
